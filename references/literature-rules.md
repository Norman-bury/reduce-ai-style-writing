# Literature and Background Rules

Use these rules for introduction, related work, background, and literature review paragraphs.

## High-Risk Skeletons

| High AI-risk expression | Lower-template direction |
|---|---|
| 围绕 X，早期研究主要依赖... | 有关 X，早期大多依靠... |
| 这类方法在特定区域和数据条件下能够获得可用结果 | 此类方法在一定区域和特定数据条件下可以得到可利用的结果 |
| 推动...向...方向发展 | 使...朝着...方向发展 |
| 端到端特征学习逐渐成为重要路线 | 端到端特征学习成了主要途径 / 成为较常用路线 |
| 任务重心由 A 转向 B | 任务重心从 A 转变为 B |
| 仍受到...影响 | 还存在...问题 |
| 为增强...能力，A 被引入... | 为了提高...能力，把 A 用在... |
| 利用 / 采用 | 用 / 使用 |
| 语义判别 | 语义识别 |
| 主要约束 | 主要限制 / 仍然限制... |

## Style Direction

- Reduce formal review openings such as `围绕`, `已有研究通过`, and `这些研究说明`.
- Prefer concrete causal wording over stacked abstract nouns.
- Allow ordinary words such as `但是`, `一般`, `可以`, `问题`, `用`, and `把`.
- Keep citations and citation order unchanged.

## Guardrails

- Do not invent time, region, data, or method conditions.
- Do not collapse separate cited claims into one broad claim.
- Do not make the literature review sound like casual commentary.
